# Перебудова даних мапи
Послідовність кроків описано в `docs/ARCHITECTURE.md` (розділ «Перебудова мапи»). Потрібні Node.js і Python 3 (numpy, Pillow).
У `tools/` виконайте `npm install`, щоб отримати mapshaper, topojson-client, d3-geo, i18n-iso-countries.
Проміжний файл `world.json` (клітини країн і морська мережа) лежить у `tools/build-data/world.json`.
