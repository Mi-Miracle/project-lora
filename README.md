# Project LORA

Геополітична стратегія в реальному часі на мапі світу: економіка регіонів, ресурси й торгівля, логістика, дипломатія й блоки, війна з окремими видами військ і техніки, космос, розвідка, компанії й персонажі. Українська та англійська мови. Створена для стрімів на Twitch: глядачі можуть грати разом зі стрімером або дивитися гру.

## Як запустити (Windows)
- **Окремий застосунок:** `Project LORA-win32-x64\Project LORA.exe` — власне вікно гри без браузера (F11 — повний екран, Ctrl+F5 — перезавантажити). Збирання: `desktop/build.sh` (потрібен Node.js).
- `Створити ярлик на робочому столі.bat` — ярлик на робочий стіл (на .exe, якщо він є).
- `Запустити LORA.bat` — запуск у браузері через локальний сервер (порт 8642). Для джерела OBS у браузері — посилання з вкладки «Стрім і звук».

## Режими
- **Одиночна гра** — за державу, компанію або персонажа.
- **Хост онлайн-гри** — стрімер відкриває кімнату; на стартовому екрані є вкладки «Гра», «Twitch», «Онлайн і посилання», «Стрім і звук». Посилання для гравців (`?join=КОД`), глядачів (`?watch=КОД`) і джерело OBS (`?watch=КОД&obs=1`).
- **Гравець** — приєднується за кодом або посиланням і обирає державу.
- **Глядач** — бачить усю мапу без туману війни, нічим не керує.

Вивід на стрім — одне джерело OBS з трьома режимами (геймплей / мапа / стрічка новин): F9 — по колу, Ctrl+Alt+1/2/3 — напряму.

## Де що лежить
- `index.html` — гра; `overlay.html` — оверлей для OBS
- `src/sim/` — симуляція світу (економіка, війна, дипломатія, космос, розвідка…); `src/ai/` — ШІ держав; `src/ui/` — інтерфейс; `src/net/` — онлайн; `src/stream/` — Twitch
- `data/` — усі числа гри (країни, ресурси, будівлі, технології, моделі техніки, компанії, сценарії) — можна правити без програмування
- `docs/` — дизайн (`GAME_DESIGN.md`), етапи (`ROADMAP.md`), архітектура, онлайн, Twitch, стрім
- `tools/` — сервер, генератори даних, перекладів і піксельних іконок, тести (`tools/test/`)
