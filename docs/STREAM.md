# Інтеграція зі стрімом (заготовка)

## Що є зараз
- `src/stream/bridge.js` транслює події гри у канал `BroadcastChannel('lora')` і (якщо задано) у WebSocket.
- Типи повідомлень: `news`, `war`, `peace`, `capture`, `state` (раз на ігровий тиждень: країна, дата, ВВП, стабільність, війни).
- `overlay.html` — прозорий оверлей: стан держави вгорі зліва, важливі новини внизу.
- Вхідні команди: `LORA.stream.onCommand(fn)` — сюди в майбутньому прийдуть голосування й дії глядачів.

## Як спробувати
1. Запустіть `Запустити LORA.bat` (піднімає http://localhost:8642).
2. Відкрийте гру: http://localhost:8642/index.html
3. В OBS додайте джерело «Браузер» → URL `http://localhost:8642/overlay.html`, 1920×1080.
   (BroadcastChannel працює між вкладками одного браузера; для OBS потрібен WebSocket-ретранслятор — етап 6.)

## Плани (етап 6)
- Невеликий ретранслятор (Node.js або Python) між грою, OBS і Twitch (EventSub / IRC-чат).
- Голосування чату: «оголосити війну?», «яку технологію досліджувати?», «яку подію запустити?».
- Бали каналу / донати → бонуси або кризи, глядач як персонаж-агент на мапі.
- Налаштування в `src/core/config.js` → `stream: { enabled, websocketUrl }`.
