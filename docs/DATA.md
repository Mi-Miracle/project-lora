# Джерела даних

- **Кордони регіонів, міста, рельєф** — Natural Earth (naturalearthdata.com), суспільне надбання. Регіони: admin-1 1:10m; міста: populated places 1:10m (українські назви — поле NAME_UK); рельєф: NE1_50M_SR_W.
- **Кордони держав для логістики** — world-atlas (Natural Earth 1:110m).
- **Назви країн українською** — бібліотека i18n-iso-countries.
- **Економіка, армії, видобуток** — наближені значення 2024–2026 рр. з відкритих джерел (МВФ, Світовий банк, EIA, USGS, FAO, IISS). Округлені; це модель, не довідник.
- **Центри видобутку** (`data/econ/hotspots.js`) — укладено вручну за відомими родовищами й промисловими кластерами.
- **Лінія фронту сценарію 2026** — спрощено до рівня областей.
