# Twitch: вхід, чат, трансляція

## Вхід через Twitch (нік і аватарка)
1. Відкрийте https://dev.twitch.tv/console → Applications → **Register Your Application**.
2. Name: будь-яка (напр. `Project LORA`), **OAuth Redirect URL**: адреса, з якої ви відкриваєте гру, наприклад `http://localhost:8642/index.html` (сервер запускає `Запустити LORA.bat`). Category: Game Integration. Client Type: Public.
3. Скопіюйте **Client ID** → у грі меню ⚙ → «Twitch Client ID» → «Зберегти».
4. На стартовому екрані «🟣 Увійти через Twitch». Гра бере лише публічні дані (нік, аватарка); токен не зберігається.
> З `file://` вхід не працює — Twitch вимагає зареєстровану http-адресу.
> Якщо гості грають зі своїх ПК, вони теж відкривають гру з http-адреси, яку ви додали в Redirect URL (можна додати кілька, або викласти гру на GitHub Pages / Netlify і вказати ту адресу).

## Чат каналу і голосування
Меню ⚙ → «Канал для чату» → «Підключити чат» (вхід не потрібен, лише читання). Коли випадає рішення-дилема — кнопка «Нехай вирішить чат (30 с)»: глядачі пишуть `!1`, `!2`, `!3`.

## Стартовий екран хоста
Режим **«Хост онлайн-гри»** має вкладки:
- **Гра** — сценарій, складність, туман війни, ваша держава;
- **Twitch** — вхід, Client ID і Redirect URL, канал для читання чату, голосування чату за дилеми й світові події;
- **Онлайн і посилання** — нік, максимум гравців, дозвіл глядачів; після «Відкрити кімнату» — посилання для гравців (`?join=КОД`), для глядачів (`?watch=КОД`) і джерело OBS (`?watch=КОД&obs=1`), вони ж є в лобі;
- **Стрім і звук** — режим виводу за замовчуванням, автокамера, музика, озвучка, випуски новин.

Глядачі й джерело OBS бачать світ **без туману війни**. Швидкістю гри керує лише хост.

## Вивід на стрім — одне джерело, три режими
Одне джерело OBS, яке показує те, що ви вибрали в грі:

| Режим | Що показує |
|---|---|
| 🎮 Весь геймплей | повний інтерфейс; джерело повторює вашу вкладку, виділення й камеру, позначка ● LIVE |
| 🗺 Лише мапа | мапа з арміями, фронтами й ударами, дата, гравці, війни; автокамера на гарячі бої (або ваша камера) |
| 📰 Лише стрічка | біжучий рядок суттєвих подій на прозорому тлі (під ним видно решту вашої сцени) |

**Перемикання:** F9 — наступний режим, Alt+1 / Alt+2 / Alt+3 — напряму, кнопка 📺 у верхній панелі — меню.

**Як підключити:**
- *Через онлайн-кімнату (рекомендовано):* відкрийте кімнату як хост, у меню 📺 скопіюйте адресу `index.html?watch=КОД&obs=1` і додайте в OBS одне джерело «Браузер» 1920×1080. Ви граєте у своєму вікні як звичайно, а джерело саме перемикається між режимами. За бажанням — «Також показувати режим у цьому вікні».
- *Без кімнати:* режим застосовується просто у вікні гри — захоплюйте його в OBS як «Вікно».
